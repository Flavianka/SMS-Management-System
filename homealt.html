Understanding SMS Delivery Status

Undelivered
The recipient's phone might be switched off or out of service range.
Usually resolves automatically when phone is back in network coverage.
Route Not Defined
The recipient is using a non-Safaricom carrier (Airtel, Telkom, etc.).
Messages to other networks may have limited delivery guarantees.
Invalid User
Phone number either has incorrect format or no user exists with that number.
Verify the phone number format (should be 2547XXXXXXXX) and contact details.
Blacklisted Sender
User has blocked promotional messages from STANNSCH sender ID.
Ask recipient to dial *456*9*5#, select "Activate by Sender Name," and enter "STANNSCH"
Delivered
Message successfully delivered to recipient's phone.
Confirmed receipt by the mobile network.
Sent/Submitted
Message accepted by SMS gateway and queued for delivery.
Awaiting delivery confirmation from mobile network.
